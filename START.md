# Reusable Codex prompt

Paste this into a Codex chat opened in this repository.

```text
Use the job-search-assistant skill in .agents/skills/job-search-assistant/SKILL.md.
Help me get started with my job search. Ask whether I want to run the fictional
demo, evaluate a posting I already have, or set up a recurring search. For my
own search, ask for my résumé and the basic criteria you need, then use my
answers to take the next step. Show me which roles fit and why, and prepare
a tailored résumé PDF and application packet for roles I select. If I want
a morning search, help me set up and test a Codex scheduled task. Wait for my
approval before sending candidate data to an employer, and for my explicit
approval of the final form before submitting an application.
```

To jump directly into the fictional example, paste this instead.

```text
$job-search-assistant Run the fictional demo from worked-example.md. Evaluate
the posting, make and grade a tailored résumé PDF, and show the application
review packet. Use only the fictional inputs and stop at the review.
```
