# Job Search Assistant

When someone asks to start a job search, try the demo, evaluate a posting, schedule a scout, tailor a résumé, or prepare an application, use the [job search skill](.agents/skills/job-search-assistant/SKILL.md). Start with the [launch prompt](START.md) if their intended mode is unclear.

Keep candidate inputs, search history, and generated application materials in the ignored `.job-search/` directory or in candidate-approved private storage. Keep demo records in `.job-search/demo/`. Never add either directory's contents to Git or publish them.
